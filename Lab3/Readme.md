# Convolutional Neural Networks - CIFAR-10 Image Classification

CS3807 – Deep Learning Laboratory, Experiment 3 - Convolutional Neural Networks

A Convolutional Neural Network built with TensorFlow/Keras to classify images into 10 categories using the CIFAR-10 dataset, covering convolution fundamentals, pooling, feature map visualization, and a full classification pipeline.

## Overview

This project covers the full pipeline end to end:

- Dataset exploration (ten sample images, class distribution)
- Convolution fundamentals - kernel size comparison (3x3 / 5x5 / 7x7) and a stride/padding comparison (stride 1 vs 2, same vs valid), both checked against the output-size formula
- Feature map visualization from an untrained convolution layer (8 feature maps)
- A CNN built in Keras - Conv(16, 3x3) → ReLU → MaxPool → Conv(32, 3x3) → ReLU → MaxPool → Flatten → Dense(10, Softmax), trained for 20 epochs
- Evaluation (accuracy, precision, recall, F1-score, confusion matrix, classification report)
- Max pooling vs average pooling comparison
- Additional exercises - output-size and parameter-count calculations (each verified against an actual Keras layer), ReLU vs Sigmoid activation, and the effect of increasing the first layer's filters from 16 to 64

## Results

| Metric | Value |
|---|---|
| Training Accuracy | 76.61% |
| Testing Accuracy | 65.84% |
| Precision | 66.77% |
| Recall | 65.84% |
| F1-score | 66.04% |
| Parameters | 25,578 |
| Training Time | 115.95 s |

Trained for 20 epochs at batch size 32 (Adam), on the full 50,000-image training set (45,000 train / 5,000 validation) and evaluated on the 10,000-image test set. Average pooling reached slightly higher accuracy than max pooling under otherwise identical settings (67.38% vs 65.84%), and increasing the first layer's filter count from 16 to 64 gave a small further gain (67.05%) at a higher parameter count and training time.

## Dataset

CIFAR-10 Dataset — loaded from the standard Python-pickled batch files (`data_batch_1` to `data_batch_5`, `test_batch`, `batches.meta`), matching the format described on the official CIFAR-10 page.

- 60,000 32×32 color images total (50,000 train / 10,000 test), 10 classes
- Classes perfectly balanced (5,000 training images per class)
- Get it from: https://www.cs.toronto.edu/~kriz/cifar.html (CIFAR-10 python version)

## Getting Started

### 1. Clone the repository

```
git clone https://github.com/<your-username>/<your-repo-name>.git
cd <your-repo-name>
```

### 2. Set up a virtual environment (recommended)

```
python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
```

### 3. Install dependencies

```
pip install -r requirements.txt
```

### 4. Run the notebook

This notebook is built for **Google Colab** - it mounts your Google Drive to read the CIFAR-10 batch files, and installs Times New Roman via `apt-get` for the figures. Open it in Colab, update the `DATASET_DIR` variable near the top to point at wherever your copy of the CIFAR-10 batches lives in your Drive, then run all cells top to bottom.

No GPU is required (this is a small two-layer CNN), but training is a little faster with one.

To adapt it for a plain local Jupyter setup instead, drop the `google.colab.drive` mount and the `apt-get` font-install cell, and point `DATASET_DIR` at a local folder containing the CIFAR-10 batch files.
