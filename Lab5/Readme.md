# CNN Training, Regularization and Transfer Learning - Oxford-IIIT Pet Classification

CS3807 – Deep Learning Laboratory, Experiment 5 - Comprehensive Study of CNN Training, Regularization, Optimization, Hyperparameter Tuning, Transfer Learning and Cross-Validation

A MobileNetV2-based pipeline built with TensorFlow/Keras on the Oxford-IIIT Pet dataset, comparing weight initializations, regularization methods, optimizers and hyperparameters on a frozen backbone, then comparing feature extraction against fine-tuning and selecting a final configuration with 5-fold cross-validation.

## Overview

This project covers the full pipeline end to end:

- Bottleneck feature caching - the frozen MobileNetV2 backbone is run once over the dataset, and every frozen-backbone study below trains a small classifier head on the cached 1280-dimensional features instead of re-running the backbone each time
- Weight initialization comparison (Zero, Random, Xavier/Glorot, He)
- Regularization comparison (No Regularization, L2, Dropout, Batch Normalization) with an overfitting check
- Batch Normalization worked numerical example, plus a with/without comparison
- Optimizer comparison (SGD, Momentum, RMSProp, Adam)
- Controlled one-at-a-time hyperparameter sweep (learning rate, batch size, dropout rate)
- Transfer learning - feature extraction vs. fine-tuning the last block of MobileNetV2 on real images
- 5-fold cross-validation across four candidate configurations
- Final model evaluation (confusion matrix, per-class precision/recall/F1, sample misclassified images)
- Additional exercise comparing two new hyperparameter combinations against the selected configuration

## Results

### Final model (selected via cross-validation)

| Metric | Value |
|---|---|
| Mean CV Accuracy | 91.88% |
| CV Standard Deviation | 0.90 |
| Test Accuracy | 90.46% |
| Precision | 90.97% |
| Recall | 90.46% |
| F1-score | 90.45% |
| Parameters | 168,741 |
| Training Time | 2.63 s |

Selected from four frozen-backbone configurations using 5-fold cross-validation on the 3,680-image training split, then retrained on the full training + validation data and evaluated once on the untouched 3,669-image test set.

### Cross-validation configurations

| Configuration | Mean CV Accuracy | SD |
|---|---|---|
| C1: Best Init Only | 91.77% | 0.74 |
| C2: Best Init + Best Reg (selected) | 91.88% | 0.90 |
| C3: Best Init + Best Reg + Best Optimizer | 91.68% | 0.76 |
| C4: Best Hyperparameters | 91.68% | 0.82 |

Fine-tuning was left out of cross-validation since it would require 20 separate end-to-end training runs. Note that the plain baseline (default initialization, no regularization, untuned Adam) reached a slightly higher standalone test accuracy (90.43%) than several of the individually tuned configurations, though all are within about two points of each other; see the full report for the complete breakdown.

## Dataset

Oxford-IIIT Pet Dataset — loaded automatically through `tensorflow_datasets`. No manual download or Google Drive setup needed, unlike Lab3/Lab4's CIFAR-10 pickle files.

- 7,349 images total (3,680 official train / 3,669 official test), 37 cat and dog breeds
- The official train split is further divided 90/10 into 3,312 training images and 368 validation images
- Downloads automatically (~800 MB) the first time the notebook runs
- Official page: https://www.robots.ox.ac.uk/~vgg/data/pets/

## Getting Started

### 1. Clone the repository

```
git clone https://github.com/<your-username>/<your-repo-name>.git
cd <your-repo-name>
```

### 2. Set up a Python 3.10 virtual environment

TensorFlow only has native GPU support on Windows through version 2.10, which requires Python 3.10 specifically. If you're on Linux, WSL2, or Mac, any recent Python 3.9+ works fine with a normal current TensorFlow install instead — drop the version pin in `Lab5_requirements.txt`.

```
py -3.10 -m venv venv
venv\Scripts\Activate.ps1     # Windows PowerShell
source venv/bin/activate      # Linux / Mac / WSL2
```

### 3. Install dependencies

```
pip install -r Lab5_requirements.txt
```

On native Windows, using the GPU also needs CUDA Toolkit 11.2 and cuDNN 8.1.1 installed separately (TensorFlow still runs on CPU without them, just much slower). Check `tf.config.list_physical_devices('GPU')` after installing to confirm it's detected.

### 4. Run the notebook

Unlike Lab3/Lab4, this notebook needs no Google Drive mount or Colab-specific setup - the dataset downloads automatically the first time it runs. Open it locally in Jupyter or VS Code and run all cells top to bottom.

Register the venv as a Jupyter kernel first if it isn't already available in your editor:

```
python -m ipykernel install --user --name lab5-env --display-name "Python 3.10 (TF 2.10 GPU)"
```

A GPU is strongly recommended for the fine-tuning section and the final retraining, which train on real images rather than cached features; everything else trains a small classifier head on cached bottleneck features and runs quickly even on CPU.
