# Transfer Learning - CIFAR-10 Image Classification

CS3807 – Deep Learning Laboratory, Experiment 4 - Comparative Study of Deep CNN Architectures Using Transfer Learning

A transfer-learning pipeline built with TensorFlow/Keras on the CIFAR-10 dataset, comparing a fine-tuned MobileNetV2 against VGG16, ResNet50, and two from-scratch architectures.

## Overview

This project covers the full pipeline end to end:

- Dataset exploration (one sample image per class)
- Transfer learning setup - MobileNetV2 with a frozen pretrained ImageNet base, `GlobalAveragePooling2D → Dense(128, ReLU) → Dense(10, Softmax)` head
- Training the frozen model, then fine-tuning the last convolutional block at a lower learning rate
- Evaluation (accuracy, precision, recall, F1-score, confusion matrix, classification report, sample misclassified images)
- Randomized hyperparameter search over learning rate, batch size, epochs, optimizer, dense units, and frozen mode, on a stratified subset
- Six additional exercises - VGG16 transfer learning, ResNet50 transfer learning, Adam vs SGD, frozen vs fine-tuned, precision/recall/F1, and a three-way LeNet-5 vs AlexNet-style vs ResNet50 comparison

## Results

### Main model (MobileNetV2, full dataset)

| Metric | Value |
|---|---|
| Training Accuracy | 86.69% |
| Testing Accuracy | 80.26% |
| Precision | 80.28% |
| Recall | 80.26% |
| F1-score | 80.24% |
| Parameters | 2,423,242 |
| Training Time | 409.02 s |

Trained frozen for 12 epochs, then fine-tuned (last block unfrozen, lr = 1e-5) for 6 more, on the full 50,000-image training set (45,000 train / 5,000 validation) and evaluated on the 10,000-image test set.

### Architecture comparison

| Model | Parameters | Accuracy | Training Time |
|---|---|---|---|
| MobileNetV2 (main, full dataset) | 2,423,242 | 80.26% | 409.02 s |
| VGG16 (transfer, subset) | 14,781,642 | 63.07% | 69.90 s |
| ResNet50 (transfer, subset) | 23,851,274 | 30.53% | 50.90 s |
| AlexNet-style (from scratch, subset) | 6,978,890 | 44.33% | 33.01 s |
| LeNet-5-style (from scratch, subset) | 83,126 | 47.60% | 11.10 s |

VGG16, ResNet50, and the two from-scratch networks were trained on a smaller stratified subset (6,000 train / 1,500 test images, 8 epochs) so the comparison would finish in a reasonable time; MobileNetV2 is the only one trained on the full dataset, so it isn't a like-for-like comparison of the architectures alone.

## Dataset

CIFAR-10 Dataset — loaded from the standard Python-pickled batch files (`data_batch_1` to `data_batch_5`, `test_batch`, `batches.meta`), matching the format described on the official CIFAR-10 page.

- 60,000 32×32 color images total (50,000 train / 10,000 test), 10 classes
- Classes perfectly balanced (5,000 training images per class)
- Get it from: https://www.cs.toronto.edu/~kriz/cifar.html (CIFAR-10 python version)

## Getting Started

### 1. Clone the repository

```
git clone https://github.com/<your-username>/<your-repo-name>.git
cd <your-repo-name>
```

### 2. Set up a virtual environment (recommended)

```
python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
```

### 3. Install dependencies

```
pip install -r requirements.txt
```

### 4. Run the notebook

This notebook is built for **Google Colab** - it mounts your Google Drive to read the CIFAR-10 batch files, and installs Times New Roman via `apt-get` for the figures. Open it in Colab, update the `DATASET_DIR` variable near the top to point at wherever your copy of the CIFAR-10 batches lives in your Drive, then run all cells top to bottom.

A **GPU runtime is strongly recommended** (Runtime → Change runtime type → GPU) - this notebook trains five separate CNNs, including VGG16 and ResNet50, and would be very slow on CPU. Pretrained ImageNet weights for MobileNetV2, VGG16, and ResNet50 are downloaded automatically the first time each is used, so the first run of each will pause briefly to fetch them.

To adapt it for a plain local Jupyter setup instead, drop the `google.colab.drive` mount and the `apt-get` font-install cell, and point `DATASET_DIR` at a local folder containing the CIFAR-10 batch files.
